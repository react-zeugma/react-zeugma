# react-zeugma

**A recursive, drag-and-drop dashboard layout engine for React.**

`react-zeugma` combines the tree-based, arbitrary splitting capabilities of `react-mosaic` with the declarative, state-driven API model of `react-grid-layout`. Built with React 18+, TypeScript, and `@dnd-kit/core`.

---

## Installation

```bash
npm install react-zeugma @dnd-kit/core @dnd-kit/utilities @dnd-kit/sortable
```

**Peer dependencies:** React 18+ or 19+

---

## Quick Start

```tsx
import { useState } from 'react';
import { DashboardProvider, PaneTree, Pane, DragHandle, TreeNode } from 'react-zeugma';

const initialLayout: TreeNode = {
  type: 'split',
  direction: 'row',
  splitPercentage: 50,
  first: { type: 'pane', paneId: 'left' },
  second: { type: 'pane', paneId: 'right' },
};

export default function App() {
  const [layout, setLayout] = useState<TreeNode | null>(initialLayout);

  return (
    <DashboardProvider
      layout={layout}
      onChange={setLayout}
      renderPane={(id) => (
        <Pane id={id}>
          {() => (
            <div>
              <DragHandle>
                <div style={{ padding: 8, cursor: 'grab' }}>{id}</div>
              </DragHandle>
              <div style={{ padding: 16 }}>Content for {id}</div>
            </div>
          )}
        </Pane>
      )}
    >
      <div style={{ width: '100vw', height: '100vh' }}>
        <PaneTree />
      </div>
    </DashboardProvider>
  );
}
```

## Core Concepts

### TreeNode

The layout is represented as a recursive tree data structure. Each node is either a **PaneNode** (a leaf containing content) or a **SplitNode** (an internal node splitting its children horizontally or vertically).

```ts
type TreeNode = PaneNode | SplitNode;

interface PaneNode {
  type: 'pane';
  paneId: string;
}

interface SplitNode {
  type: 'split';
  direction: 'row' | 'column';
  splitPercentage: number; // 0–100
  first: TreeNode;
  second: TreeNode;
}
```

### 5-Zone Drag & Drop

When you drag a pane header over another pane, five drop zones appear:

| Zone       | Action                                                                     |
| ---------- | -------------------------------------------------------------------------- |
| **Top**    | Splits the target pane vertically, placing the dragged pane on top         |
| **Bottom** | Splits the target pane vertically, placing the dragged pane on the bottom  |
| **Left**   | Splits the target pane horizontally, placing the dragged pane on the left  |
| **Right**  | Splits the target pane horizontally, placing the dragged pane on the right |
| **Center** | Swaps the dragged pane with the target pane                                |

### Resizing

Drag the split bars between panes to resize them. The `splitPercentage` value updates in the tree state accordingly.

## What's in a Name?

> **Zeugma** is an ancient Greco-Roman city located on the banks of the Euphrates River in Gaziantep, Turkey. Founded by one of Alexander the Great's generals around 300 BC, it became a thriving cultural crossroads between East and West.
>
> The city is world-renowned for the **breathtaking mosaic panels** unearthed during archaeological excavations — intricate compositions of thousands of tiny tiles (_tesserae_) forming stunning scenes. Many of these mosaics are now preserved in the [Zeugma Mosaic Museum](https://en.wikipedia.org/wiki/Zeugma_Mosaic_Museum), one of the largest mosaic museums in the world.

Just as Zeugma's artisans assembled countless small tiles into grand compositions, `react-zeugma` lets you assemble **many panes into one unified dashboard layout** — each piece distinct, yet all part of a larger mosaic.
